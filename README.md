# 📋 О проекте

Этот проект представляет собой **локального ИИ-преподавателя** по технической термодинамике, который отвечает на вопросы студентов, используя:

- 📚 **Ваши учебные материалы** (PDF файлы в папке `/books`)
- 🔍 **Векторный поиск** для нахождения релевантных фрагментов
- 🤖 **Локальную LLM** (через Ollama) для генерации ответов
- 💬 **Историю диалога** для поддержания контекста

Всё работает **полностью локально** — без интернета, без API ключей, без ограничений!

---

# ✨ Возможности

## 📖 Работа с учебными материалами
- Автоматическая загрузка и индексация PDF файлов из папки `/books`
- Разбиение на чанки с сохранением контекста
- Векторное представление для семантического поиска

## 🤖 Локальный ИИ
- Поддержка любой модели Ollama (qwen3, llama3, mistral, gemma)
- Полностью офлайн работа
- Нет ограничений на количество запросов

## 💬 Умный диалог
- Понимание контекста разговора
- Ответы только на основе учебных материалов
- Честное "не знаю", если информации нет

## 🛡️ Безопасность
- Фильтрация политических тем
- Защита от токсичных выражений
- Rate limiting для предотвращения спама

# 🔧 Установка

## 📋 Пошаговая установка

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/дкарабарин/Команда-ИИ-агентов-3.git
cd Команда-ИИ-агентов-3
2. Установите Ollama и модель
bash
# Установите Ollama с официального сайта https://ollama.com
# Затем скачайте модель (рекомендуется qwen3:4b для русского языка)
ollama pull qwen3:4b

# Альтернативные модели:
# ollama pull llama3.2:3b  # английская, 3B параметров
# ollama pull mistral:7b   # мощная, но требует больше RAM
# ollama pull gemma2:2b    # легкая, быстрая
3. Создайте виртуальное окружение
bash
# Windows
python -m venv .venv
.venv\Scripts\activate

# Linux/Mac
python3 -m venv .venv
source .venv/bin/activate
4. Установите зависимости
bash
pip install -r requirements.txt
5. Подготовьте учебные материалы
bash
# Создайте папку для книг
mkdir books

# Поместите PDF-файлы в папку books/
# Например: books/термодинамика.pdf
6. Запустите бота
bash
python bot-local-ollama.py
📖 Использование
Первый запуск
При первом запуске программа автоматически:

проверит наличие Ollama

проиндексирует все PDF-файлы из папки /books

создаст векторную базу данных в /chroma_db

запустит интерактивный интерфейс
