📋 О проекте
Этот проект реализует систему RAG (Retrieval-Augmented Generation) для работы с термодинамическими материалами. Бот использует локальные PDF-файлы и векторную базу данных для предоставления точной информации по запросам.

🔍 Возможности
Поддержка термодинамических концепций: энтропия, термодинамические процессы, уравнения состояния.
Интерфейс на Python: интеграция с Ollama для работы с моделями.
Локальное хранение данных: все данные сохраняются локально без необходимости интернет-соединения после установки моделей.
Поддержка нескольких моделей: выбор между qwen3:4b (русский), llama3.2:3b (английский), mistral:7b и gemma2:2b.
🛠 Установка
Убедитесь, что Ollama запущена и доступна:

ollama serve
Скачайте репозиторий:

git clone https://github.com/your-username/project-name.git
cd project-name
Создайте папку books для PDF-файлов:

mkdir -p books
Запустите индексацию:

python rag.py
Запустите бота:

python bot-local-ollama.py
Примечание: Для больших PDF-файлов может потребоваться увеличение объема оперативной памяти.

🎥 Демонстрация
Запрос: Что такое энтропия?

Ответ:

Энтропия — это функция состояния, характеризующая меру неупорядоченности системы.
В термодинамике она определяется формулой: dS = δQ/T

Основные свойства:
• В обратимых процессах ΔS = 0
• В необратимых процессах ΔS > 0
• Энтропия изолированной системы не убывает (второй закон термодинамики)

📚 Источники:
• thermodynamics_book.pdf
Запрос: А формула есть?

Ответ:

Да, основная формула для изменения энтропии:
ΔS = ∫ δQ/T

Для идеального газа при постоянной температуре:
ΔS = R·ln(V₂/V₁)

Где:
• ΔS — изменение энтропии
• δQ — элементарное количество теплоты
• T — абсолютная температура
• R — газовая постоянная
• V₁, V₂ — начальный и конечный объёмы
