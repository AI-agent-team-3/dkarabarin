# 🔥 Thermodynamics RAG Assistant

Локальный ИИ-ассистент для изучения технической термодинамики с поддержкой RAG (Retrieval-Augmented Generation), веб-поиск через Tavily и полной наблюдаемостью через Langfuse.

---

## 📚 Особенности

- **RAG на PDF-документах** — загружайте учебники и методички в папку `books/`
- **Локальная LLM через Ollama** — бесплатно, без интернета
- **Веб-поиск через Tavily** — актуальная информация из интернета
- **Полная наблюдаемость через Langfuse** — трассировка всех запросов
- **Гибридный поиск** — сначала PDF, затем веб-поиск, затем LLM
- **Консольный интерфейс** — удобная работа без Telegram

---

## 🚀 Быстрый старт

### 1. Установка Python 3.11

### 2. Установка Ollama
#### Загрузите модель
ollama pull qwen3:4b

### 3. Получение API ключей
#### Tavily API (веб-поиск):
#### Зарегистрируйтесь на app.tavily.com
#### Получите бесплатный API ключ (1000 запросов/мес)
#### Langfuse (опционально, для наблюдаемости):
#### Запустите локально через Docker или используйте cloud.langfuse.com
### 4. Клонирование и установка
git clone 
cd thermodynamics-rag
python -m venv venv

#### Активация виртуальной среды:
### Linux / Mac
source venv/bin/activate
### Windows
venv\Scripts\activate.bat
pip install -r requirements.txt
### 5. Настройка окружения
cp .env.example .env
#### Отредактируйте .env и вставьте ваши ключи API
### 6. Подготовка базы знаний
mkdir books
#### Поместите PDF-файлы по термодинамике в папку `books/`
### 7. Запуск Langfuse (опционально)
docker compose up -d
### 8. Запуск ассистента
python local_rag.py

📚 PDF ОТВЕТ:
======================================================================
Энтропия — это мера беспорядка или хаоса в термодинамической системе.
Согласно второму закону термодинамики, энтропия изолированной системы
не может уменьшаться, она может только возрастать или оставаться
постоянной в обратимых процессах.

Формула: dS = δQ/T, где:
• dS — изменение энтропии
• δQ — количество теплоты
• T — абсолютная температура

# Советы по решению проблем

Уменьшите параметры CHUNK_SIZE, CHUNK_OVERLAP, K_RETRIEVAL в rag.py.
