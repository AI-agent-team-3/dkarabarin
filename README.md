# 🔥 Thermodynamics RAG Assistant

Локальный ИИ-ассистент для изучения технической термодинамики с поддержкой RAG (Retrieval-Augmented Generation), веб-поиском через Tavily, полной наблюдаемостью через Langfuse и **современным веб-интерфейсом**.

---

## 📚 Особенности

### Основные функции
- **RAG на PDF-документах** — загружайте учебники и методички в папку `books/`
- **Локальная LLM через Ollama** — бесплатно, без интернета
- **Веб-поиск через Tavily** — актуальная информация из интернета
- **Полная наблюдаемость через Langfuse** — трассировка всех запросов
- **Гибридный поиск** — сначала PDF, затем веб-поиск, затем LLM

### 🆕 Новые функции веб-интерфейса
- **Красивый веб-чат** — современный интерфейс с анимациями
- **Поддержка LaTeX формул** — красивое отображение математических выражений
- **Markdown форматирование** — жирный текст, курсив, списки
- **Адаптивный дизайн** — работает на ПК, планшетах и телефонах
- **Индикатор печати** — анимация набора текста ботом
- **История диалогов** — сохраняется в браузере
- **Экспорт/импорт чата** — сохраняйте важные диалоги
- **Статусная панель** — отображение состояния RAG, поиска и модели
- **Горячие клавиши** — Enter для отправки, Shift+Enter для новой строки

### Режимы работы
1. **Консольный режим** — для терминала (`python bot-local.py`)
2. **Веб-режим** — через браузер (`python -m uvicorn web.api:app`)
